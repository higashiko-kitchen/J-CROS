# J-CROS | Japan Crisis Response Operating System

大規模災害時における全国規模の意思決定支援・リソース最適配置システム

## 概要
J-CROSは、公的防災データ（国交省・気象庁）および Google Maps / Earth ビューを統合し、南海トラフ巨大地震等の広域有事におけるリアルタイム状況把握（Vision）、支援部隊の動態監視（Resource）、AIによる最適輸送ルート算定（Logistics）を統合制御するシステムです。

## 主な機能
- **南海トラフ巨大地震 発生シミュレーション**: 想定震源域・津波波及帯・広域避難ルートの動的描画
- **Google Maps / Earth 連携**: 衛生写真・航空写真ビューと通常地図のシームレス切り替え
- **公的ハザードマップ連動**: 国土交通省「重ねるハザードマップ（津波・土砂災害）」タイルの直接リアルタイム重畳
- **J-CROS AI Engine**: 自衛隊・消防・DMATの広域動員指示と啓開道路の自動提示
